# RedLibertad V1.81.1 — Event Date Validation Hotfix

- El campo "Termina" mantiene un mínimo igual al inicio y limpia automáticamente valores iguales o anteriores al inicio.
- El formulario valida en cliente que la fecha de fin sea válida y posterior a la de inicio.
- El error backend `invalid_end` ahora se muestra como mensaje claro en español.
- PWA cache renovada.
