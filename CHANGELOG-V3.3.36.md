# V3.3.36 — Participación: abrir la publicación correcta

- El visor de publicación ahora descarta respuestas tardías: si se abren dos publicaciones seguidas, solo se muestra la más reciente solicitada.
- Cerrar la ventana invalida peticiones pendientes, para que el contenido no vuelva a pintarse después de cerrarla.
- Si cambia la sesión mientras se recupera una publicación, se cierra el visor sin mostrar información que pertenecía a la cuenta anterior.
- Se mantienen todos los permisos del endpoint actual, las acciones de comentarios/reacciones y el diseño móvil y de escritorio. No hay nuevas llamadas, métricas, correos, mensajes automáticos ni migraciones.
