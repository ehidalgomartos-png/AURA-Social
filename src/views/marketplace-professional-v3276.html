2. Todas las tiendas

Comprueba la cuenta propietaria antes de conectar WooCommerce o importar productos. La propiedad de los anuncios importados será la de esa cuenta. Solo se permite transferir tiendas en borrador sin productos vinculados ni credenciales de API guardadas.

3. Vincular un producto publicado

Indica el ID de uno de tus anuncios de venta y la dirección real del producto en tu tienda. El botón de compra solo aparece tras aprobar la tienda y si el producto tiene existencias.

Productos vinculados

El vínculo manual solo relaciona la ficha existente y el producto de la tienda; para productos WooCommerce usa la revisión de duplicados del apartado 5. Nunca pegues claves de tu tienda en este formulario.

4. WooCommerce · conexión API de solo lectura

Elige tu tienda WooCommerce. Se utilizará una clave de API con permiso Lectura; no solicitamos acceso a pedidos ni cobros. Las claves se cifran en el servidor y nunca se muestran de nuevo.

5. Revisar e importar productos

Primero revisa los productos de WooCommerce. Se mostrarán coincidencias con anuncios anteriores. Puedes importar los productos nuevos o vincular un anuncio del mismo vendedor, previa revisión. Las publicaciones existentes no se borrarán ni cambiarán de propietario.

Importar varios productos a la vez

Selecciona únicamente productos nuevos sin coincidencias. Máximo 10 por lote, también entre páginas. Los existentes deben vincularse individualmente. No se publicará nada hasta que confirmes la selección.

0 de 10 productos seleccionados.

Confirmación antes de publicar

    Cada producto se volverá a comprobar en WooCommerce y contra los anuncios existentes antes de publicarse. Los que tengan duplicados o errores se detendrán individualmente; los publicados correctamente no se eliminarán si falla otro.
