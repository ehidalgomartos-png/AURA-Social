Importar desde WooCommerce

Sube el CSV de productos exportado desde WooCommerce. Primero verás una vista previa; no publicaremos nada sin tu confirmación.

Debes iniciar sesión para importar productos.

Iniciar sesión

1. Elige el CSV, el origen y el ámbito de venta

WooCommerce → Productos → Exportar → Generar CSV. Compatible con productos simples, SKU o ID y URL de imágenes HTTPS.

Se aceptan productos simples publicados y con existencias. Las fotografías se descargarán al VPS por HTTPS. Asegúrate de tener derecho a utilizarlas.

2. Revisa los productos

Los productos con errores o duplicados no se publicarán. Cada producto válido necesita SKU o ID y al menos una foto compatible.

3. Importación por lotes

Puedes pausar y continuar desde este dispositivo. El progreso se guarda en RedLibertad. No cierres esta página si deseas ver la importación en tiempo real.
