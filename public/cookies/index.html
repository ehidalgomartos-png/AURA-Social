TECNOLOGÍAS DEL NAVEGADOR

Cookies y almacenamiento local

Qué tecnologías utiliza actualmente RedLibertad y para qué sirven.

Versión 1.0Vigente desde 7 de octubre de 202618+

1. Situación actual

RedLibertad no necesita utilizar cookies publicitarias ni tecnologías de publicidad comportamental de terceros para prestar sus funciones actuales. La aplicación puede utilizar almacenamiento del navegador y cookies o mecanismos estrictamente necesarios para sesión, seguridad, preferencias y funcionamiento técnico.

2. Tecnologías técnicas

Entre las tecnologías que pueden utilizarse se encuentran:

  • almacenamiento local o de sesión para conservar preferencias, estado de navegación, contexto de retorno y funciones PWA;
  • credenciales o tokens técnicos necesarios para mantener una sesión autenticada;
  • caché del Service Worker para permitir funcionamiento PWA, mejorar rendimiento y cargar recursos estáticos;
  • identificadores temporales de seguridad o limitación de abuso mantenidos en el servidor.

3. Analítica y publicidad

En la configuración actual descrita por esta política no se integran Meta Pixel, Google Analytics ni redes publicitarias de terceros. Las métricas de producto y atribución que utiliza RedLibertad son internas y se orientan a operación, seguridad y mejora del servicio.

4. Consentimiento

Las tecnologías estrictamente necesarias para prestar un servicio solicitado por el usuario pueden utilizarse sin un consentimiento específico de cookies. Si en el futuro se incorporan tecnologías no necesarias que requieran consentimiento, esta política se actualizará y se implantará un mecanismo que permita aceptar o rechazar de forma válida antes de cargarlas.

5. Cómo borrar datos del navegador

Puede cerrar sesión, borrar los datos del sitio desde la configuración del navegador y, en el caso de una PWA instalada, eliminar la aplicación o sus datos almacenados. Esto puede cerrar la sesión o restablecer preferencias.
