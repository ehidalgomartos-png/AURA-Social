# RedLibertad V1.81.0 — Public Events & Event SEO

Continuación directa sobre V1.80.2 estable.

## Incluye
- Directorio público `/eventos`.
- Búsqueda y filtros presencial/online.
- Solo eventos realmente públicos, no cancelados y de creadores elegibles.
- Protección adicional para eventos ligados a comunidades.
- Ficha canónica `/evento/:id/:slug`.
- Structured Data `Event`.
- Sin exposición de URL privada de eventos online.
- Sin identidades públicas de asistentes.
- Contadores solo cuando `attendee_visibility=public`.
- Nuevo `/sitemap-events.xml`.
- Integración con sitemap index, sitemap principal, robots y navegación pública.
- Índices PostgreSQL para eventos públicos.
- Mobile-first.
- Sin monetización.
