# RedLibertad V2.3.0 — Registro legal legible

## Funciones
- Descarga HTML legible e imprimible desde la cuenta, con datos exclusivos del usuario autenticado.
- Exportación JSON anterior conservada sin cambios por defecto.
- HTML autocontenido, sin recursos externos ni JavaScript, con CSS móvil e impresión A4.
- Fecha de generación en UTC, versiones vigentes en momento de descarga, historial completo y registro legacy honesto.
- Datos de usuario y documento escapados, CSP restrictiva, descarga attachment, no-store y nosniff.
- Avisos expresos: registro informativo, no certificado digital ni archivo de textos históricos.
- Actualización a 2.3.0 (health, panel admin, package, PWA y documentación).
- Ocho pruebas nuevas del HTML, junto a las 12 pruebas legales existentes.

## No cambia
- Tablas, consentimiento y versiones legales 1.0.
- Rutas de publicaciones y monetización.
- API JSON en su formato por defecto.

## Validación
`npm run check:syntax` y `npm run test:legal`, además de las pruebas manuales del checklist.
