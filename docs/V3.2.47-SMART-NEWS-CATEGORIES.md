# RedLibertad V3.2.47 — Noticias Inteligentes 2.1

## Categoría recomendada (sin coste API)
Tras analizar un enlace HTTPS, el panel «Una noticia, una pantalla» propone Deportes, Tecnología, Cultura, Sociedad, Entretenimiento o Actualidad, basándose en la ruta, el titular y el extracto de la fuente. La sugerencia **no modifica datos hasta que el administrador la revise**, puede corregirse manualmente y no implica verificación de hechos. Si las señales son contradictorias o débiles, no se fuerza ninguna clasificación y se pide seleccionar la categoría.

## Noticia pública
Se elimina el texto fijo «Actualidad para conversar» de cada noticia. Se usa una etiqueta legible de la categoría almacenada en la publicación, saneada mediante lista cerrada. Las noticias deportivas muestran «Deportes para conversar», culturales «Cultura para conversar», etc.

## IA editorial
Las solicitudes de IA admiten una categoría estrictamente validada mediante enum. Una guía editorial específica del tema, de texto fijo y no inyectable por la fuente, complementa las restricciones existentes: no inventar resultados, fechas, declaraciones, cifras ni hechos. La IA sigue siendo manual y de pago solo cuando se solicita.

## Regresión
Suite: npm run test:editorial-categories. Mantiene la aprobación, calidad, atribución, límites de gasto y publicación manual de V3.2.46. Verificar visualmente en móvil y escritorio después del despliegue.
