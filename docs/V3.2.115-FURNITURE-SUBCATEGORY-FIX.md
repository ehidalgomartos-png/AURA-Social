# RedLibertad V3.2.115 — Categorías detalladas de muebles WooCommerce

## Error reproducido
Los anuncios de la categoría CSV **«Armarios Puertas Batientes»** son visibles en el catálogo filtrado, pero la página SEO **/marketplace/muebles** de V3.2.114 aparecía vacía. La V3.2.114 reconocía categorías generales («Armarios», «Sofás», «Salones») pero no «Armarios Puertas Batientes».

## Solución
- Reconocer nombres completos de subfamilias habituales: «Armarios Puertas Batientes», «Armarios Puertas Correderas», «Armarios 2/3/4 puertas», «Sofás 2/3 plazas», etc., sin clasificar productos no relacionados.
- Mantener la clasificación sincronizada entre JavaScript (enlaces de producto) y PostgreSQL (conteos, fichas, sitemap).
- Preservar la categoría original del CSV y los datos de todos los productos ya importados. No reimportar ni cambiar precios, fotos o permisos.
- Mantener **/marketplace/muebles** para muebles nuevos, usados o sin condición declarada y **/marketplace/muebles-segunda-mano** exclusivamente para artículos expresamente marcados como usados.
- Sustituir el texto público que hablaba de CSV y WooCommerce por información útil para compradores.

## Calidad e indexación
La página general de muebles solo se indexa y aparece en el sitemap si tiene al menos cinco anuncios realmente visibles de vendedores activos y descubribles. Con menos anuncios, permanece `noindex,follow` y no se promociona como una colección completa.

## Comprobaciones
- Prueba JavaScript `npm run test:marketplace-furniture-subcategories`: caso «Armarios Puertas Batientes», falsos positivos, privacidad de anuncios, nuevos/usados y links.
- PostgreSQL 18 con tablas temporales y categorías reales: al menos cinco armarios deben aparecer en /marketplace/muebles, nunca en segunda mano si no constan como usados; privacidad y sitemap condicionados; regresiones existentes obligatorias.
- Tras desplegar: abrir https://redlibertad.com/marketplace/muebles, verificar fotos y anuncios que ya figuran bajo el filtro «Armarios Puertas Batientes», confirmar sitemap y entonces solicitar indexación en Search Console.

## Restricciones
Sin cambios de facturación, Stripe LIVE, tarifas, IVA o aceptación legal. No alterar anuncios de MundoTaza, WooCommerce, fotos o productos. Las compras siguen realizándose exclusivamente en la web del vendedor cuando exista enlace verificado.
