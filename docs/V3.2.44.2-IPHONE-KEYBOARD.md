# RedLibertad V3.2.44.2 — iPhone Keyboard Viewport Hotfix

El compositor del chat aparecía recortado arriba y mostraba la bandeja por debajo al enfocarlo con teclado iOS. Safari desplaza `visualViewport.offsetTop` cuando la barra del teclado abre, mientras el chat estaba fijo en top 0 aunque medía `visualViewport.height`.

Esta corrección alinea alto y top del panel fijo con el viewport visual; evita offsets negativos y resincroniza tras el enfoque diferido. No altera la lógica del envío, navegación Back, base de datos ni privacidad.

## Validación en dispositivo real (pendiente)
1. Safari iPhone: Mensajes > conversación > campo de escritura, cabecera e input visibles; no debe aparecer la bandeja de fondo.
2. Escribir varias líneas; cerrar y abrir teclado; enviar mensaje.
3. Repetir en PWA iOS si está instalada.
4. Android: Atrás devuelve a la lista y al resto de secciones.
5. Entradas al chat desde Perfil, Personas y Mensajes.

Esperar autorización expresa para fusionar.
