# V3.2.133 — Conexión del comparador con tiendas españolas

## Alcance
Se incorpora un proveedor de resultados reales para el comparador de RedLibertad a través de SerpApi / Google Shopping (parámetros `gl=es`, `hl=es`), sobre las páginas permanentes ya existentes.

- Resultados con **nombre del producto, tienda, precio EUR, fotografía segura y aviso de envío**, cuando el proveedor los ofrezca.
- Se distinguen los enlaces **directos a la tienda** de los enlaces al catálogo de **Google Shopping**; estos últimos NO son un checkout del vendedor.
- Las búsquedas genéricas (por ejemplo `iphone`) muestran *productos relacionados*. Solo las consultas de modelo específico pueden aprobarse como una comparación de un único producto para SEO.
- No inventamos precios, disponibilidad, gastos de envío, marcas ni valoraciones. La compra siempre se realiza fuera de RedLibertad.
- Se filtran accesorios, modelos incompatibles y precios que indiquen una moneda distinta de EUR.
- Caché persistente en PostgreSQL: no se vuelve a consultar SerpApi para la misma búsqueda antes de 24 horas.
- Los errores del proveedor no borran las ofertas guardadas; se indica al usuario que son datos anteriores.
- Cuando no hay clave válida, la web sigue mostrando los anuncios locales y páginas guardadas sin fallar.

## Activación manual en Coolify
1. Crear o acceder a una cuenta en https://serpapi.com/ y consultar el plan disponible y sus límites antes de activar nada.
2. Generar la API key en la cuenta de SerpApi.
3. En la aplicación **RedLibertad** de Coolify → Environment Variables, crear `COMPARADOR_SERPAPI_KEY` con la clave **como secreto**, nunca en el navegador, GitHub o un archivo público.
4. Opcionalmente ajustar `COMPARADOR_DAILY_LIMIT=5` y `COMPARADOR_MONTHLY_LIMIT=100` (valores por defecto recomendados, límites máximos aplicados por esta versión: 50/día, 250/mes).
5. Guardar y desplegar desde el `main` correspondiente **solo tras fusionar** esta versión.
6. En `/comparar` buscar `iphone 17 pro`, y comprobar que se conservan el título, el precio en euros, la tienda, la fecha y que el enlace funcione.
7. Repetir la consulta: dentro de 24 horas no debe gastar otro crédito de SerpApi; otro producto distinto sí consume una consulta dentro del presupuesto.
8. Si no deseas realizar más consultas externas, elimina la API key o fija `COMPARADOR_DAILY_LIMIT=0` y `COMPARADOR_MONTHLY_LIMIT=0` y vuelve a desplegar.

**Importante:** La versión no realiza compras ni registra cuentas de pago. La mera preparación del código no activa SerpApi. Los créditos y su precio son los que indique el proveedor en tu cuenta (a fecha de la revisión, el plan Free publicado anunciaba 250 búsquedas/mes, sujeto a cambios).

## Especificaciones de seguridad y calidad
- Consulta a un único endpoint predefinido HTTPS de SerpApi, no se permite que el usuario suministre URLs.
- Token antifalsificación CSRF para enviar la consulta; rate limit 15 solicitudes/hora/IP heredado.
- Clave de API solo en la aplicación del servidor. No hay scripts de terceros que lean el token.
- Cuotas de consultas compartidas entre procesos mediante contadores atómicos de PostgreSQL dentro de una transacción.
- Los resultados solo admiten enlaces HTTPS externos sin credenciales y fotos de proveedores conocidos de Google/SerpApi. URLs de productos locales se mantienen internas.
- Etiqueta `noindex` para páginas sin revisión editorial, o genéricas, y `Product/AggregateOffer` solo para modelos concretos con al menos dos vendedores.
- No existe enlace directo garantizado a cada tienda: `product_link` puede ser una página de Google Shopping.
