# RedLibertad V3.2.105 — Preparación de facturación para España

**Base:** V3.2.104 (`c5325d457540f270d16d9ef2af37348d590f5035`).

## Objeto

Preparar para revisión profesional un mapa de los requisitos que habrá que resolver antes de contratar Profesional y Profesional Plus en España. Continúan los tres tipos de cliente acordados: particular, autónomo y empresa. Los importes de laboratorio no son precios definitivos.

### Cuatro escenarios de contratación

| Cliente | Uso declarado | Pendiente |
| --- | --- | --- |
| Particular | Personal | Documento de facturación adecuado, datos mínimos, obligaciones de consumidor |
| Autónomo | Personal | No presumir contratación empresarial; revisar derechos de consumidor |
| Autónomo | Profesional | Datos para factura, NIF cuando proceda, identificación del destinatario |
| Empresa | Empresarial | Identificación fiscal, razón social, domicilio y factura conforme a normativa |

**No es una lista cerrada ni definitiva de datos legalmente obligatorios.** Antes de solicitar información habrá que confirmar el servicio, régimen fiscal, requisitos de factura y bases legales para cada caso. Una persona autónoma puede contratar con finalidad personal.

### Ámbito territorial

Se conservan tres escenarios: **Península y Baleares**, **Canarias**, y **Ceuta y Melilla**. Todo es España a efectos del lanzamiento, pero no tiene un único tratamiento impositivo automático. El IVA español solo se aplica territorialmente en Península y Baleares; la localización concreta de cada prestación debe revisarse. No se fija ningún porcentaje, exención, cargo automático, retención ni régimen sustitutorio.

Fuentes de referencia para la futura asesoría:
- Agencia Tributaria, [obligación de facturar](https://sede.agenciatributaria.gob.es/Sede/iva/facturacion-registro/facturacion-iva/obligacion-facturar.html).
- Agencia Tributaria, [contenido de factura ordinaria](https://sede.agenciatributaria.gob.es/Sede/ayuda/manuales-videos-folletos/manuales-practicos/manual-iva-2026/capitulo-10-obligac-formales-suj-registro/obligaciones-materia-facturacion/contenido-general-facturas-ordinarias.html).
- Agencia Tributaria, [territorio del IVA](https://sede.agenciatributaria.gob.es/Sede/ayuda/manuales-videos-folletos/manuales-practicos/manual-iva-2024/capitulo-02-introduccion/territorio-que-se-aplica-impuesto.html).

## Implementación

- Servicio `src/services/marketplace-billing-preflight-v32105.js` con cuatro escenarios de uso, tres territorios y ocho revisiones pendientes; todo es privado y **de solo lectura**.
- Integración en la respuesta del panel administrativo de preparación del lanzamiento, bajo `billingPreflight`.
- Panel de información plegado inicialmente para no recargar la interfaz móvil. No es un formulario de alta, no almacena nombres, NIF, domicilio, datos fiscales ni solicita consentimiento.
- Corrección de un error anterior en la previsualización de planes: la variable local `preview` ocultaba la función de previsualización, provocando fallo al mostrar los planes. Se añade prueba de ejecución con DOM simulado para que el fallo no reaparezca.
- Prueba automática `npm run test:marketplace-billing-preflight` en GitHub Actions; la prueba incluye los flags de bloqueo y el comportamiento del navegador simulado.
- No se añaden tablas ni variables de entorno. No se ejecuta Checkout de producción ni se habilita facturación.

## Puertas pendientes

1. Confirmación jurídica y fiscal de la entidad emisora de las suscripciones.
2. Datos mínimos por finalidad de compra y derechos del consumidor, sin inferirlos del tipo de cuenta.
3. Localización del servicio, impuestos por territorio y facturas, incluyendo rectificaciones y conservación.
4. Contratos definitivos y consentimiento/versionado, aprobados expresamente.
5. Precios finales y autorización independiente para Stripe LIVE; diseño e implementación posterior del Checkout comercial y pagos fallidos.

**MundoTaza** conserva el piloto gratuito, WooCommerce, fotografías y productos. Los compradores continúan pagando en la web del vendedor. La preparación fiscal no limita el acceso internacional al Marketplace ni concede permisos de pago.
