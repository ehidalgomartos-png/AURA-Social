# V3.2.48.1 — Hotfix de Noticias (GET /noticias)

**Causa raíz:** la ruta de listado `publicRouter.get('/', async(_req,res) => {...})` leía `req.query.categoria`, variable sin definir. El catch devolvía HTTP 503 y el texto "No disponible".

**Solución:** cambiar el parámetro del manejador a `req`. Mantener toda la lógica anterior para filtros, artículos públicos, comentarios y recomendaciones. No modifica la base de datos.

**Prevención:** pruebas que invocan la ruta GET con consulta vacía, `categoria=deportes`, categoría inválida y artículo relacionado usando SQL simulado. La respuesta debe ser 200 o redirección segura, nunca un falso error 503. Se incluyen en GitHub Actions.

**Despliegue:** fusionar solo tras SUCCESS y autorización del propietario; esperar Coolify, verificar /api/health=3.2.48.1, /noticias, /noticias?categoria=deportes y /noticias/p/9.
