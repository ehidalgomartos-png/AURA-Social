# RedLibertad V3.2.89 — Preparación del lanzamiento comercial (solo administración)

Base `main` V3.2.88: `5d73472e6c4b08891948993caa4a58e5a13b8e3c`.
Rama: `redlibertad-v3.2.89-commercial-launch-readiness`.

## Nueva vista
- En **Preparación comercial** se añade acceso a `/marketplace/suscripciones/lanzamiento` (solo administradores, noindex y no-store).
- Panel de preflight de **Profesional** y **Profesional Plus**: posibles precios mensuales internos, límite propuesto de 1 y 3 tiendas, catálogo sin límite comercial propuesto, alta individual frente a importación CSV/sincronización automática, checkout del producto en la web del vendedor.
- Lista de comprobación de cada plan: precio propuesto, consistencia de prestaciones, checkout externo, seis apartados del contrato redactados, y borrador en revisión interna.
- Seis revisiones transversales: precios, IVA/facturación, condiciones/consentimiento, renovaciones, cancelaciones/reembolsos y privacidad.
- Ensayo **privado** del texto del vendedor seleccionando cada modalidad; permite inspeccionar los seis apartados del borrador. No se hace visible en la web del vendedor.
- Si no hay propuesta de precio, aparece «Por definir»; si hay importe, aparece explícitamente «propuesta privada», nunca precio en vigor.

## Protección frente a activaciones prematuras
- API de solo lectura `GET /api/marketplace/subscriptions/admin/commercial/launch-readiness` bajo `requireAdmin`.
- Incluso si todos los textos y revisiones internas están completados, la respuesta mantiene `releaseAuthorized=false`, `productionReady=false`, `legalApproval=false`, `taxApproval=false`, `billingEnabled=false`, `liveStripeEnabled=false` y `pricesPublished=false`.
- No hay API de publicación, alta, checkout, cargos ni consentimiento del vendedor. El botón de contratación está **deshabilitado**.
- **No se modifican tiendas, vendedores, fotos, importadores, WooCommerce, SEO ni Google Merchant.**
- El piloto gratuito de MundoTaza no pierde su condición ni la sincronización.
- Stripe TEST sigue aislado para administradores; Stripe LIVE no está disponible.

## Despliegue y validación
- `npm run check:syntax`, `npm run test:marketplace-launch-readiness`, suite de regresión y GitHub Actions.
- Solo tras autorización de fusión: hacer Redeploy en Coolify **sin variables nuevas** y abrir Preparación comercial → Vista previa del lanzamiento.
- Comprobar que los importes son privados, que se indican los pendientes, cambiar de Profesional a Plus, y que «Contratar» está deshabilitado.
- Comprobar que desde la cuenta del vendedor no se accede a la nueva ruta y que su Centro de contratación sigue sin mostrar borradores internos.

## Pendiente antes de cualquier lanzamiento comercial real
Confirmar tarifas e impuestos con asesoría fiscal, contrato/legal y privacidad, políticas de renovación/cancelación, versión de consentimiento vinculante, QA de cobros y autorizaciones expresas separadas. La revisión interna nunca equivale a publicación aprobada.
