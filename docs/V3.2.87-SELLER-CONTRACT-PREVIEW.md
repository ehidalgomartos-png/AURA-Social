# RedLibertad V3.2.87 — Centro de contratación profesional (solo simulación)

Base estable `1e242e50f5f6e6624772a9d8006e923d43ba06b6`; rama `redlibertad-v3.2.87-seller-contract-preview`.

## Experiencia para vendedores
- Acceso privado desde **Mi tienda → Centro de contratación profesional** (`/marketplace/contratacion`). Requiere autenticación y responde noindex, no-store.
- Comparativa mobile-first de Profesional y Profesional Plus: 1/3 tiendas propuestas, sin límite comercial propuesto para productos, alta uno a uno frente a CSV/lotes + sincronización WooCommerce.
- **No publica importes internos ni presenta 9,90 / 24,90 euros como precios vigentes**. Aparece «Precio definitivo pendiente» mientras la preparación comercial y fiscal no esté aprobada.
- Explica una futura contratación mediante Stripe Billing, periodicidad de renovación, importes/impuestos, aceptación expresa de condiciones, bajas, reembolsos y gestión de facturas. Indica claramente lo que aún debe decidirse.
- Una simulación local de elección de plan → revisión informativa → dos confirmaciones de comprensión → resumen. **Las casillas NO son aceptación contractual**, nunca se persisten, y no hay checkout real ni envíos de datos de pago.
- Si el vendedor tiene tiendas aprobadas o un piloto registrado, se le advierte de que sus condiciones actuales no cambian; no se le solicita migración.
- La compra y el pago de cada producto siguen realizándose en la web de cada vendedor.

## Seguridad
- Nuevo GET `/api/marketplace/subscriptions/contract-preview`, accesible únicamente con sesión y derivado del usuario autenticado; nunca acepta un seller ID del navegador.
- La respuesta es lectura solamente: sin borradores privados de precios, sin Stripe API, sin claves, sin datos personales ni endpoints de activación.
- No se añade ninguna mutación de suscripciones, consentimientos, planes operativos, tiendas ni inventario.
- Stripe LIVE y suscripciones reales siguen desactivados; el laboratorio Stripe TEST permanece solo para admins y aislado.
- MundoTaza conserva su piloto gratuito y sincronización WooCommerce existentes.
- No nuevas variables de Coolify ni cambios de base de datos.

## Próximas fases
Para permitir contratación real se requerirán términos legales finales, precios e impuestos aprobados, gestión de renovación/cancelación, privacidad, verificación fiscal y aprobación expresa de Stripe LIVE. La presente versión no anticipa esos permisos.
