# RedLibertad V3.2.80.1 — Hotfix Stripe TEST Checkout

**Base:** `main` `2a718f8fe995f59e04de9b7e13e8833a23503f00` (V3.2.80). Sin cambios de versión técnica general, sin migraciones y sin modificación de variables de Coolify.

## Error detectado
Stripe TEST rechazaba `POST /v1/checkout/sessions` con `Invalid line_items[0]: the product tax code is missing` porque la cuenta tenía **Managed Payments habilitado por defecto**. El propio error recomienda establecer `managed_payments[enabled]=false` para desactivarlo exclusivamente en esa sesión.

## Corrección
- Añadir `managed_payments[enabled]=false` únicamente al formulario de creación de Checkout de `src/services/marketplace-stripe-test-v3280.js`.
- Extender pruebas existentes para verificar que el parámetro está presente y se serializa correctamente a `application/x-www-form-urlencoded`.
- Conservar los precios `price_...` y claves Stripe TEST actuales; **no** cambiar la configuración global de Managed Payments ni añadir códigos fiscales arbitrarios.
- Sin operaciones en Stripe LIVE, sin Stripe Connect, sin modificar `marketplace_seller_subscriptions`, tiendas aprobadas, catálogos, imágenes, enlaces externos ni permisos.

## Aceptación
- GitHub Actions y `npm run test:marketplace-stripe-test` superados.
- Tras fusionar únicamente con autorización, redeploy en Coolify **sin cambiar variables**.
- En el laboratorio, probar «Profesional → Abrir Stripe Checkout de prueba»: debe abrir Stripe TEST mostrando 9,90 €/mes. No introducir aún datos de tarjeta reales.
- En caso de nuevo rechazo, inspeccionar el código de error específico en Stripe → Workbench → Registros.
