# RedLibertad V3.2.111 — Landing SEO para el Marketplace (España)

## URL y objetivo
**URL canónica única:** https://redlibertad.com/marketplace/explorar

La ruta ya existía, era accesible sin iniciar sesión, se enlazaba desde Inicio, estaba incluida en el sitemap y ya disponía de una cuadrícula SSR con filtros, fichas SEO independientes y exclusión de anuncios no públicos. Se amplía **esa misma página**; no se genera una página puerta ni otras landings que compitan por la misma intención.

## Intenciones de búsqueda
- Primaria: anuncios de segunda mano, compraventa en España, comprar y vender.
- Secundarias reales: anuncios clasificados, muebles, móviles, vehículos, productos usados, servicios profesionales, inmobiliaria y venta nacional.
- Los nombres de competidores (Wallapop / Milanuncios) sirven como referencia de mercado, **no** se insertan en titles, contenido o metadatos, ni se usan afirmaciones no verificables de liderazgo.

## Contenido
- Titular único H1, descripción útil, botones para buscar y publicar, enlaces a filtros reales.
- Resultados de anuncios reales visibles **antes** del contenido largo para priorizar las necesidades móviles.
- Categorías coherentes con la taxonomía existente, instrucciones de uso, alcance geográfico y preguntas frecuentes.
- Mensaje claro: búsqueda pública sin registro, contacto mediante cuenta/chat y compras/pagos **solo en la web del vendedor** si existe enlace verificado. Sin promesas de disponibilidad, inventario, transacción garantizada o publicidad gratuita para vendedores.
- Hoja CSS mobile-first, respetando focos visibles, objetivos táctiles y ancho 320–360 px.

## SEO técnico
- Canonical existente, HTML SSR, title/description y Open Graph/Twitter mediante el shell público.
- Datos JSON-LD: WebSite, CollectionPage y BreadcrumbList. **No** se marca la portada como Product, Offer, FAQ rich result o Merchant Listing; estos datos solo se usan cuando corresponde a la página específica.
- Filtros con query string siguen siendo `noindex,follow`; página raíz indexable, paginación previa intacta.
- El sitemap `/sitemap-marketplace-1.xml` ya incluye `/marketplace/explorar`, y `robots.txt` la permite. Sin URLs duplicadas, redirecciones nuevas ni permisos modificados.
- Enlace semántico de pie de página desde la portada principal.

## Verificación
`npm run test:marketplace-seo-landing`; GitHub Actions: regresiones completas, sintaxis JS y suite PostgreSQL 18 anterior.

Después de desplegar: comprobar HTML de la URL pública (200, H1, canonical, title, JSON-LD, anuncios), recursos CSS (200), móvil a 320–390 px, sitemap, y solicitar indexación o inspeccionar la URL en Search Console. Medir **impresiones, consultas y CTR**, no prometer puestos en Google.

## Límites
No activa pagos Stripe LIVE, planes, permisos de contratación, precios definitivos, cambio de IVA, WooCommerce, datos y productos de MundoTaza. No implementa pagos internos; las compras continúan en tiendas externas.
