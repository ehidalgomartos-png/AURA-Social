# V3.2.81.1 — Optimización visual del panel comercial

Base: main de RedLibertad V3.2.81, commit 80f4b5e154e8f70a27f485174a6460d75ea50573.
Rama: redlibertad-v3.2.81.1-compact-commercial-panel. No fusionar sin autorización.

## Por qué
El panel comercial funciona pero con los dos formularios y seis revisiones abiertos ocupa demasiada altura, especialmente en móvil.

## Cambios
- Resumen compacto con número de planes, revisiones pendientes y revisadas; se actualiza al guardar.
- Planes Profesional y Profesional Plus agrupados como tarjetas desplegables accesibles con \`<details>/<summary>\`, nativas para teclado y pantalla táctil.
- Las seis revisiones se muestran como filas plegadas con nombre, contexto y estado; al abrir una se ven selector, notas y botón Guardar.
- El flujo de contratación previsto se mantiene, ahora dentro de un bloque desplegable.
- Etiquetas descriptivas, foco accesible, objetivos táctiles >= 42px, contraste y diseño mobile-first; sin librerías externas.
- Las notas, descripciones, importes y estados guardados se cargan desde la misma API actual, sin borrar información.
- El formulario no se pliega automáticamente al guardar; conserva la posición y anuncia el resultado sin perder entradas.
- Actualización del cache-busting CSS/JS a V3.2.81.1.
- Pruebas de panel colapsado, conteos, actualización del estado después de guardar, API y garantías de acceso.

## Invariantes
- No altera servicios, rutas, SQL, modelo de datos ni condiciones del Marketplace.
- No modifica MundoTaza ni las tiendas piloto, imágenes, anuncios o enlaces a WooCommerce.
- No habilita Stripe LIVE, checkout, cuotas, registro de pagos ni suscripciones comerciales.
- Se mantiene el laboratorio Stripe TEST existente, sin cambiar variables de Coolify.

## Validación
\`npm run check:syntax\`, \`npm run test:marketplace-commercial\`, \`npm run test:marketplace-commercial-compact\` y GitHub Actions.
Tras fusión con autorización, redeploy en Coolify, probar abrir/cerrar las ocho secciones, guardar una nota no sensible y recargar para verificar persistencia; repetir en móvil.
