# RedLibertad V3.2.48 — Noticias y Descubrimiento 3.0

## Exploración sin saturar Inicio
- Página /noticias: navegación horizontal mobile-first con Todas / Actualidad / Deportes / Tecnología / Cultura / Sociedad / Entretenimiento.
- Consulta segura de noticias únicamente **publicadas y con perfil listo**; categoría solo de lista cerrada, resto redirige a la URL canónica.
- Los filtros se representan con ?categoria=..., noindex/follow y canonical /noticias; el sitemap no añade URLs de filtros.
- En las tarjetas, acceso directo a lectura y a la conversación real de una noticia. Los contadores de reacciones siguen siendo del servicio existente: no se inventan comentarios ni actividades.
- La noticia pública sugiere hasta **tres noticias de la misma categoría**, nunca borradores ni contenido retirado. No aparecen recomendaciones si no las hay.
- Sin publicidad extra ni tarjetas nuevas en Inicio. Se conserva la cadencia actual: dos publicaciones sociales, una noticia.

## Garantías
No se modifica la lógica de importación, la IA de pago, cuotas, moderación, privacidad, aprobación, SEO de artículos, sistema de perfiles ni publicación manual. Las noticias relacionadas se extraen del mismo filtro público de publicaciones activas.

## Validación
\`npm run test:editorial-discovery\`, regresión general de GitHub y comprobación visual móvil/escritorio de pestañas, artículos relacionados y enlaces a comentarios.
