# RedLibertad V3.2.84 — Simulador de permisos de planes profesionales

**Base estable:** V3.2.83, main `954129ed224420576f2ed6acec05ff155e52afd7`.
**Rama:** `redlibertad-v3.2.84-plan-permissions-simulator` — no fusionar sin autorización.

## Objetivo
Preparar una vista previa administrativa de las futuras reglas de cada modalidad, sin publicar tarifas, sin bloquear importadores y sin cobrar suscripciones reales.

## Qué incluye
- Sección «Simulador de permisos» dentro de `/marketplace/suscripciones/comercial`, con diseño mobile-first.
- Modos de prueba: **Profesional**, **Profesional Plus** y **Piloto existente**.
- Escenarios hipotéticos: alta de un producto, CSV/lotes, sincronización WooCommerce, conectar una tienda y compra fuera de RedLibertad.
- Cantidades de tiendas/productos ficticias. No se utiliza información de un vendedor real.
- Profesionales: se distingue la publicación individual de la carga masiva. Plus contempla CSV y sincronización; los pilotos siguen exentos de límites comerciales.
- Si hay topes propuestos, se compara con ellos. Si el límite de productos aún no se ha fijado, el resultado indica la incertidumbre; nada se impone en producción.
- Endpoint POST de solo lectura `/api/marketplace/subscriptions/admin/commercial/preview`. Admin autenticado, origen controlado, rate limit y campos estrictamente validados.
- Motor puro de simulación, con indicadores `previewOnly=true`, `limitsEnforced=false`, `billingEnabled=false`.

## Restricciones explícitas
- **No se modifica ninguna ruta real** de publicación, importación, sincronización, compra ni autorización.
- No se cambian tablas, registros, planes de pago, permisos, inventarios, tiendas, anuncios, imágenes, datos de usuarios o facturas.
- MundoTaza mantiene su piloto gratuito, el vínculo WooCommerce y las ventas en su propio checkout.
- Los precios 9,90/24,90 EUR siguen siendo referencias internas; Stripe LIVE sigue desactivado.
- No se añaden variables Coolify ni hay migraciones de vendedores.
- La aprobación de tienda, la seguridad del enlace, moderación y disponibilidad siguen aplicándose por separado.

## Fase futura independiente
Conservar la idea de desarrollar RedLibertad como comparador CSS para Google Shopping cuando reúna suficiente número de comercios y ofertas comparables. No implementarlo dentro de esta versión ni confundirlo con Merchant Center de cada vendedor.

## Validación
`npm run check:syntax`, `npm run test:marketplace-commercial-preview`, pruebas de las versiones 3.2.81–83 y GitHub Actions.
Tras aprobación de fusión: Redeploy en Coolify sin cambiar variables. Probar Profesional + CSV (previsto no), Profesional Plus + CSV (previsto sí), Piloto + CSV (sin límites comerciales), y conectar una segunda tienda bajo Profesional (propuesta lo impediría).
En producción actual, todos esos resultados son exclusivamente informativos, no operativos.
