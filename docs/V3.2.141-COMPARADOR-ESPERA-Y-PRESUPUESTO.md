# V3.2.141 — Aprovechar cuota gratuita y mostrar una espera agradable

## Problema real
El 25/10/2026 el usuario mostró el panel de SerpApi con **6 de 250** búsquedas utilizadas, mientras RedLibertad ya bloqueaba solicitudes por sus propios límites (`5/día, 100/mes`). En la búsqueda nueva «iphone 12 128 GB» aparecía dos veces «Límite de consultas externas alcanzado», más «Todavía no hay ofertas» y un bloque de tiendas vacío.

## Cambios
- Límites **predeterminados**: `COMPARADOR_DAILY_LIMIT=12`, `COMPARADOR_MONTHLY_LIMIT=220`; quedan **30 consultas del plan de 250 como reserva** en el presupuesto interno. Si se configura un valor mensual mayor, el código limita a 220; se pueden configurar valores menores. Máximo diario configurable: 50, recomendado 12.
- **Avisos internos fuera de la web pública**: se eliminan los mensajes sobre SerpApi, consumo o cuotas de las fichas. En `/admin/comparador` se muestran las consultas usadas hoy y este mes frente a los límites configurados. Es el contador **local de RedLibertad**, que no sustituye al contador global de SerpApi ni contempla consultas hechas manualmente fuera de la web.
- Si faltan resultados y el proveedor no pudo consultarse, aparece **una sola tarjeta amable**: «Estamos preparando esta comparación», explicando que el enlace se conserva y ofreciendo «Ver otras comparaciones». No afirma que se hayan encontrado ofertas ni muestra precios inventados.
- Si una búsqueda termina correctamente pero sin coincidencias: «Todavía no encontramos ofertas». Si está procesando una consulta, estado «Buscando ofertas para tu producto». Se mantiene el refresco automático ya disponible.
- Con ofertas guardadas, se mantienen tarjetas, enlaces y precios aunque se haya agotado el presupuesto.
- Una comparación **sin ofertas** cuyo intento fue bloqueado por cuota puede volver a encolarse tan pronto como se renueve el presupuesto, sin quedar bloqueada 24 horas por una comprobación que nunca se efectuó. La fecha `last_checked_at` se conserva, en vez de aparentar una actualización.
- Reglas SEO, sitemap, enlaces de tiendas, precios y límites de seguridad permanecen intactos.

## Importante en Coolify
Los valores explícitos de las variables de entorno prevalecen sobre los predeterminados. Si actualmente Coolify tiene guardados:
```
COMPARADOR_DAILY_LIMIT=5
COMPARADOR_MONTHLY_LIMIT=100
```
**hay que sustituirlos por**:
```
COMPARADOR_DAILY_LIMIT=12
COMPARADOR_MONTHLY_LIMIT=220
```
y desplegar. Sin este paso, el servicio seguirá aplicando 5/100 aunque GitHub haya fusionado la nueva versión. No se modifica `COMPARADOR_SERPAPI_KEY`, ni se puede comprobar desde GitHub qué variables existen realmente en Coolify.

La cuota compartida cubre búsquedas de productos y consultas de fichas de vendedores. Se sigue reutilizando la caché de 24 horas para reducir el consumo.
