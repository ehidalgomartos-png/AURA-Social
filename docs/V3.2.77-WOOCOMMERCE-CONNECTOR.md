# RedLibertad V3.2.77 — WooCommerce API de solo lectura (piloto)

Base: main V3.2.76, commit ca24aa4af1f46e22da2b1052d0a8580fe1fbbe42.

## Objetivo
Conectar una tienda WooCommerce existente desde el panel de administración; importar productos con URL original, descripción, precio, categoría, stock y hasta cuatro fotografías al almacenamiento local, sin checkout propio ni dinero custodiado.

## Instalación
1. Coolify: añadir una variable secreta MARKETPLACE_WC_ENCRYPTION_KEY, obtenida ejecutando openssl rand -base64 32 (32 bytes en Base64). Conservarla en el gestor de secretos y copias cifradas; NO cambiarla sin migrar las credenciales cifradas existentes. No enviarla por chat.
2. WooCommerce: Ajustes → Avanzado → REST API → Añadir clave, permisos Solo lectura. Requiere autorización del dueño de la tienda.
3. RedLibertad: iniciar sesión como administrador en /marketplace/tiendas. Registrar tienda WooCommerce. Enviar a revisión y aprobar solo tras comprobar titularidad del dominio, políticas de compras y pago.
4. Seleccionar tienda en el bloque WooCommerce, pegar Consumer Key y Secret y conectar. Las claves se prueban sobre HTTPS, cifran con AES-256-GCM y nunca regresan al navegador.
5. Indicar ciudad/provincia y ámbito. Previsualizar 20 productos por página; importar individualmente con confirmación expresa.
6. Verificar el botón Comprar en la tienda en ficha pública y el chat de RedLibertad; pago exclusivamente en checkout del vendedor.
7. Sincronizar ahora: hasta 20 productos asociados a esta API. Habilitar sincronización automática opcional para revisiones aproximadamente cada 6 horas (worker cada 15 min con reserva en PostgreSQL).

## Límites y salvaguardas
- Solo administradores en las rutas HTML y API. No URLs con credenciales ni claves en logs.
- WooCommerce API: solo operaciones GET /wp-json/wc/v3/products.
- Protección SSRF: HTTPS obligatorio, DNS público IPv4 fijado, sin redirecciones, máximo 1 MB de JSON, timeout de 8 segundos. Fotografías descargadas con el importador seguro existente.
- Enlace de compra en el dominio exacto de la tienda autorizada.
- Productos simples publicados y con datos completos. Variantes/variables, paquetes, drafts y productos externos se omiten. Las fotos nuevas después de la importación no se vuelven a descargar automáticamente.
- La sincronización no importa productos nuevos automáticamente. Cada producto debe revisarse y confirmarse primero. Los anuncios importados históricamente por CSV siguen intactos y no se enlazan automáticamente (IDs de WooCommerce de distintas tiendas pueden colisionar).
- Máximo 20 productos API por ciclo en este piloto. Catálogos mayores requieren paginación con cursor y seguimiento antes de habilitar automatización completa.
- Cuando falla la revisión remota de un producto, su stock pasa a desconocido y se oculta el botón de compra hasta que se vuelva a comprobar.
- Datos adicionales en tablas nuevas; sin borrar usuarios, anuncios, fotos ni importaciones anteriores.
- Sin cuotas, Stripe Connect, pedidos propios, cobros ni feed Merchant activo.

## Google Merchant
Para cada vendedor, usar la URL real de su tienda verificada/reclamada y un checkout en ese mismo dominio. RedLibertad no debe reclamar ni simular la titularidad de tiendas de terceros. No existe aprobación automática.

- npm run test:marketplace-woocommerce
- npm test y GitHub Actions
- Pruebas HTTP: admin/invitado/usuario estándar, credenciales erróneas, SSL, stock, fotos, URL y compra.

Importación por lotes con progreso, catálogos >20, variaciones, comparación segura contra CSV ya importados, actualización de fotos, monitorización y adaptadores PrestaShop/Shopify.
