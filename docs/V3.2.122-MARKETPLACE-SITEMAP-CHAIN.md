# RedLibertad V3.2.122 — Cadena completa de sitemaps y preparación para Search Console

## Punto de partida

El usuario ha validado V3.2.121 en producción. La auditoría SEO privada ofrece cifras de anuncios públicos y una muestra orientativa de hasta 100 anuncios recientes. La siguiente mejora se enfoca en facilitar el descubrimiento técnico **sin crear nuevas páginas de productos ni inventar resultados de Google Search Console**.

No se consiguió abrir los XML del sitio desde el lector web externo disponible durante esta implementación; esto **no demuestra** que fallen para los visitantes ni para Google. Los cambios se basan en código, consultas públicas existentes y pruebas.

## Error detectado y corregido

`/sitemap-index.xml` (índice principal del sitio) enlazaba directamente con `/sitemap-marketplace-1.xml` (primera página del sitemap general de anuncios), en vez de `/sitemap-marketplace.xml` (índice que enumera **todas** las páginas).

Para inventarios por encima de 2.000 anuncios públicos, el índice principal no señalaba directamente las páginas adicionales del sitemap general. El archivo `robots.txt` sí anunciaba correctamente el índice general de Marketplace, pero es preferible que **ambas fuentes sean coherentes**.

Se ha sustituido únicamente esa referencia dentro del índice global por `/sitemap-marketplace.xml`. Se conservan los enlaces a los índices especializados de productos, servicios e inmuebles y al sitemap de categorías.

## Nuevo resumen privado: «Mapa técnico de sitemaps»

Dentro de `/marketplace/seo/auditoria`, solo para administradores, se muestra una **previsión** derivada de los recuentos ya calculados de anuncios públicos y de las condiciones actuales de calidad SEO para categorías.

- Enlaces a `/sitemap-index.xml` y `/robots.txt`.
- Índice general `/sitemap-marketplace.xml` y páginas esperadas, basadas en grupos de 2.000 anuncios públicos.
- Índices `/sitemap-marketplace-productos.xml`, `/sitemap-marketplace-servicios.xml` y `/sitemap-marketplace-inmuebles.xml`, cada uno con su recuento público y primera/última página XML esperadas.
- Sitemap de categorías `/sitemap-marketplace-categorias.xml` con **solo las colecciones que cumplen los criterios internos de `canIndex`**. No se crean categorías ni se fuerzan `index` o sitemaps para páginas sin inventario.
- Los enlaces del panel se limitan a rutas locales del Marketplace. Todo texto mostrado se escribe con `textContent`, sin insertar HTML procedente de anuncios.

Cuando no existen anuncios, el sitemap general y los especializados conservan una primera página XML vacía o mínima, conforme a la implementación actual. Es una previsión técnica y **no** significa que Google haya rastreado o indexado la página.

## Sin acceso a datos de Search Console

Esta versión no conecta con Search Console ni intenta inferir qué URLs están indexadas, cuántas impresiones reciben o si el crawler ha visitado los XML. El panel indica explícitamente que solo muestra **sitemaps esperados** a partir de SQL.

Para validar la indexación real, abrir Search Console y revisar **Sitemaps, Páginas e Inspección de URLs** de los anuncios públicos. Tras desplegar, conviene comprobar manualmente el HTTP y contenido XML del índice principal, índice Marketplace y primera/última página esperadas.

## Pruebas y seguridad

- `npm run test:marketplace-sitemap-plan`: raíz del sitemap correcto, rutas, límites de 2.000 anuncios (0/2.000/2.001/4.001), sitemaps de productos/servicios/inmuebles, categorías publicables, privacidad del panel, ausencia de rutas externas o inserción HTML y metadatos canónicos/fotos existentes.
- PostgreSQL 18: tablas temporales de anuncios públicos, ocultos, pausados y vendedores privados. Los números de las páginas XML previstas deben coincidir con los recuentos **únicamente públicos**.
- Todas las regresiones anteriores siguen ejecutándose en GitHub Actions. Fusionar exclusivamente cuando los trabajos generales y PostgreSQL 18 terminen en verde y `main` siga alineado.

## Sin cambios funcionales en Marketplace

No cambia el inventario, precios, etiquetas de nuevo/usado, categorías, importaciones CSV, producto original de WooCommerce, archivos de imágenes, permisos efectivos, tienda externa, Merchant Center ni rutas canónicas de fichas. No se introducen nuevos procesos automáticos ni se activan cobros, Stripe LIVE, tarifas, IVA o documentos contractuales. MundoTaza sigue siendo piloto gratuito.

## Validación tras desplegar en Coolify

1. Abrir `https://redlibertad.com/sitemap-index.xml` y buscar un enlace a `https://redlibertad.com/sitemap-marketplace.xml` **en lugar de** `sitemap-marketplace-1.xml`.
2. Abrir `https://redlibertad.com/sitemap-marketplace.xml` y confirmar que enumera los fragmentos públicos pertinentes.
3. Entrar como administrador a `https://redlibertad.com/marketplace/seo/auditoria`, pulsar «Actualizar diagnóstico» y revisar «Mapa técnico de sitemaps».
4. Abrir los enlaces de primera y última página. Confirmar que son XML válidos con enlaces a anuncios públicos (o página vacía cuando corresponda). No considerar esto una comprobación automática: debe revisarlo una persona o Search Console.
5. Revisar **Sitemaps** en Google Search Console. Si ya se envió `/sitemap-index.xml`, la nueva referencia podrá ser descubierta en el siguiente rastreo, sin que ello garantice indexación ni un plazo concreto.
