# RedLibertad Resuelve — Avisos de confianza (V3.5.14)

## Objetivo
Resuelve es una comunidad de ayuda entre personas. Declarar experiencia profesional no equivale a verificar un título, colegiación o identidad profesional. La posibilidad de ayudar no se condiciona a una compra.

## Reportar
- Personas autenticadas pueden notificar un problema sobre la respuesta de otra persona. No pueden denunciar su propia respuesta.
- Motivos estructurados: publicidad encubierta, cualificación engañosa, datos personales, consejo potencialmente peligroso y otros.
- Una sola denuncia por usuario y respuesta. Sin campo libre para evitar recopilar datos personales innecesarios.
- Los avisos no ocultan, sancionan ni degradan automáticamente las respuestas.
- La identidad del denunciante no se muestra en la cola de moderación de esta versión y nunca se incluye en el detalle público.

## Moderación
- Solo administradores pueden consultar los avisos pendientes.
- Se muestra el contenido, la declaración profesional y el posible interés económico para revisar el contexto.
- El administrador puede desestimar el aviso o abrir la respuesta y utilizar el control existente para ocultarla.
- Al ocultar una respuesta, se cierran sus avisos pendientes. Desestimar no borra ni oculta la respuesta.
- Se registra quién desestima y cuándo. Los avisos están sujetos a límites de frecuencia, permisos, comprobación del origen y validación de motivo.

## Precauciones
- Que exista una denuncia no demuestra que la persona mienta o que la respuesta sea errónea.
- Tampoco se muestran distintivos de profesional verificado: este sistema no verifica acreditaciones.
- No hay recomendaciones automáticas de proveedores, ranking comercial ni cambio de indexación SEO.
- El historial se conserva en la base de datos para auditar decisiones y podrá recibir reglas de retención en una fase posterior.
