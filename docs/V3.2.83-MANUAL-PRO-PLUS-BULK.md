# RedLibertad V3.2.83 — Profesional uno a uno; Plus carga por lotes

**Base:** V3.2.82 estable (main `27ceca64f7f6eda6c15c61e33e46e0a52585f143`).
**Rama:** `redlibertad-v3.2.83-single-product-vs-bulk-plans`. No fusionar sin autorización expresa.

## Diferenciación solicitada
- **Profesional (plan económico)**: publicar productos uno a uno, mediante el formulario normal del Marketplace. Sin importación CSV ni carga masiva y sin sincronización automática de catálogo WooCommerce (porque de otro modo una sincronización permitiría introducir muchos productos y eludir la limitación de lotes).
- **Profesional Plus**: permite tanto la publicación individual como la importación por CSV/lotes y sincronización automática WooCommerce, **cuando las condiciones comerciales sean aprobadas en una versión futura**.
- 1 y 3 tiendas son propuestas existentes; los límites de productos siguen por definir.
- La compra de cada producto se realiza siempre en la web original del vendedor.
- Los precios de 9,90/24,90 €/mes son referencias internas, no tarifas aprobadas.

## Implementación (solo borradores)
- Valores nuevos de borrador: `professional(woo_sync=false,bulk_import=false)`; `professional_plus(true,true)`.
- Actualización aditiva e idempotente del registro de **planificación comercial** `marketplace_subscription_commercial_features` para adaptar el borrador Profesional que V3.2.82 había sembrado con los dos campos a `true`. No se toca ninguna tienda real ni inscripción existente.
- Validación del servidor: el administrador no puede proponer carga masiva ni sincronización automática en Profesional, ni desactivar los enlaces de compra externa.
- Interfaz: casillas informativas bloqueadas en Profesional y comparativa explícita (uno a uno frente a carga por lotes). En Plus se mantienen editables.
- Pruebas unitarias, controles de la API de borradores, cobertura de invariantes y CI.

## Lo que **no** hace esta versión
**No aplica ninguna restricción** a ningún vendedor, tienda, publicación, sincronización WooCommerce o importador; este estado es una **propuesta comercial privada** y no un sistema de permisos operativo. La implantación real de las modalidades de pago requerirá reglas de autorización en rutas servidor/importadores y migración explícita de vendedores cuando el usuario lo autorice.

MundoTaza permanece piloto sin cuota, sin vencimiento y sin alterar su sincronización actual. No se activa Stripe LIVE, no se publican precios, no se modifica WooCommerce, no hay Stripe Connect y no se cobra ningún pedido desde RedLibertad.

## Pruebas
`npm run check:syntax`, `npm run test:marketplace-commercial-plans`, `npm run test:marketplace-commercial-plan-tiers`, `npm run test:marketplace-commercial-compact`, CI.
Después de autorizar la fusión, redeploy en Coolify y revisar que la comparativa indique «No; solo de uno en uno» para Profesional y «Sí, propuesta Plus» para importación CSV/lotes. No cambiar variables.
