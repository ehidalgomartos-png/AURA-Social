# RedLibertad V3.2.46 — Centro Editorial Inteligente 2.0

## Qué cambia
En **Centro Editorial** hay un nuevo panel de creación rápida con URL: analizar metadatos, seleccionar perfil, aportar hechos revisados, generar un borrador de titular y resumen por IA bajo demanda, y decidir si generar una ilustración conceptual con coste de API. Tras guardar el borrador se abre automáticamente la vista previa de publicación de V3.2.45.

## Seguridad y facturación
- Nunca se confían metadatos del navegador para persistir: el endpoint web-import/save vuelve a consultar el artículo.
- La URL debe coincidir con la analizada y ser HTTPS; se detectan duplicados y se exige categoría/perfil preparado.
- La imagen solo se genera cuando el administrador elige expresamente la opción de pago. Continúan los límites de una imagen por noticia y cuotas existentes.
- Fuente, hechos, derechos y nota editorial se verifican mediante declaraciones explícitas del administrador.
- El nuevo panel **no publica automáticamente**: únicamente guarda un borrador, y opcionalmente genera imagen. La aprobación, calidad y publicación siguen siendo la confirmación final del modal V3.2.45 y los endpoints anteriores.
- Si falla la generación de imagen, el borrador ya guardado permanece en Pendientes y no se ejecuta ninguna publicación; se ofrece el enlace al editor para finalizar o revisar.
- Si no se puede extraer el artículo, se muestra un acceso al importador manual existente, no se inventan metadatos.

## Verificación
`npm run test:editorial-one-screen` y demás comprobaciones GitHub Actions. Hacer prueba real en móvil y escritorio antes de declarar estable.
