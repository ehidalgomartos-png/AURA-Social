# RedLibertad V3.2.78 — Suscripciones profesionales (arquitectura)

**Base exacta:** main \`7785ff9d322e3688adbe196354289ae2d2e55c78\` (V3.2.77.9). Rama independiente. **No fusionar sin autorización.**

## Alcance
- Modelos nuevos y aditivos: \`marketplace_subscription_plans\`, \`marketplace_seller_subscriptions\` y \`marketplace_subscription_audit\`; el catálogo usa \`INSERT ... ON CONFLICT DO NOTHING\`.
- Planes iniciales: Particular (gratis), Profesional y Profesional Plus; **precios profesionales NULL y disponibilidad false** hasta aprobación comercial. Límites orientativos internos, **no aplicados**.
- Identidad: suscripción asociada a \`seller_id\`, nunca al anuncio. Estados preparados: piloto, prueba, activa, pago pendiente, cancelada y caducada.
- GET \`/api/marketplace/subscriptions/mine\`: solo tiendas propias del usuario autenticado; sin IDs de vendedor manipulables.
- GET \`/api/marketplace/subscriptions/plans\`: catálogo para usuarios autenticados.
- GET \`/api/marketplace/subscriptions/admin/overview\`: solo administradores, **lectura**.
- Vista privada \`/marketplace/mi-tienda\`: móvil primero, con plan y tiendas propias; accesible desde «Mis anuncios» del Marketplace. HTML con noindex/no-store.
- Las tiendas aprobadas sin suscripción escrita aparecen como \`pilot\` informativo, sin cuota ni fecha de vencimiento. Esto evita reescribir tiendas existentes y protege MundoTaza.
- \`billingEnabled=false\`, \`enrollmentEnabled=false\`, \`entitlementsEnforced=false\`. No hay rutas POST, proveedor de pago, checkout, eventos de renovación ni reglas de restricción.

## Invariantes
- NO modificar \`marketplace_listings\`, \`marketplace_external_products\`, la configuración WooCommerce o la lógica pública \`purchaseLink\`.
- NO suspender compras externas, modificar sync/stock, cambiar propietarios, borrar datos ni desactivar el chat por estados de suscripción.
- Las páginas y API administrativas de WooCommerce siguen requiriendo \`requireAdmin\`; el nuevo panel del comerciante **no permite conectar credenciales ni importar**.
- El botón «Comprar en la tienda» mantiene la URL HTTPS original del vendedor; RedLibertad no procesa pagos de productos.
- El límite y precios propuestos son orientativos y no una oferta publicada. No crear filas de suscripción ni cobrar a las tiendas aprobadas durante la migración.
- Para V3.2.79: políticas de acceso futuras, consentimiento comercial, gracia por impago, auditoría de cambios y aprobación de precios. Para V3.2.80: sandbox de suscripciones, webhooks idempotentes e impuestos. Sin activar live sin autorización.
