# V3.2.80.2 — Stripe TEST: cancelación programada y reconciliación

**Base estable:** main `71cd0a2645bc7adeb0e3364b957da09698eb935d` (V3.2.80.1). **No fusionar sin autorización.**

## Motivo
El Customer Portal confirma cancelación programada al 17 de noviembre de 2026, pero RedLibertad muestra «Sin cancelación de test programada» tras recibir eventos `customer.subscription.updated`. El laboratorio solo leía `cancel_at_period_end`; Stripe también dispone de `cancel_at`, y los webhooks pueden llegar fuera de orden.

## Corrección
- Interpretar una fecha futura `cancel_at` o `cancel_at_period_end=true` de Stripe TEST como cancelación programada.
- Columna aditiva e idempotente `cancel_at TIMESTAMPTZ` **solo** en `marketplace_stripe_test_subscriptions` para mostrar la fecha exacta.
- Persistir la información en webhooks nuevos sin modificar el historial de eventos antiguos.
- Botón **«Sincronizar estado desde Stripe TEST»** en el laboratorio de administradores, disponible cuando hay suscripción de prueba; permite actualizar una suscripción ya cancelada sin volver a cancelarla.
- Consulta de solo lectura a `GET https://api.stripe.com/v1/subscriptions/:id` usando solo clave `sk_test_`; validar `livemode=false`, ID, vendedor autenticado, cliente, metadatos de sandbox, plan y precio antes de actualizar únicamente la fila TEST de ese vendedor.
- Endpoint admin `POST /api/marketplace/subscriptions/admin/stripe-test/sync` con autenticación, origen, JSON vacío, limitación de frecuencia y respuesta sin secretos. No acepta IDs arbitrarios.
- Mantener el bloqueo de Checkout de prueba duplicado y las restricciones comerciales desactivadas.

## Validación
GitHub Actions, `npm run test:marketplace-stripe-test`, `npm run check:syntax`. Tras fusión con permiso, redeploy sin modificar variables de Coolify; en el laboratorio, pulsar «Sincronizar estado desde Stripe TEST» para comprobar que se refleja la cancelación del 17/11/2026 sin repetir el proceso.

**Sin Stripe LIVE, sin cuotas comerciales, sin cambios a MundoTaza, tiendas aprobadas, WooCommerce, imágenes, anuncios, chat o enlaces externos.**
