# RedLibertad V3.2.118 — Metadatos SEO útiles para anuncios de producto

## Punto de partida
La V3.2.117 quedó validada por el usuario en producción. Las fichas públicas ya tienen URL canónica, imágenes, HTML SSR, datos estructurados, breadcrumbs y sitemaps. Sin embargo, para los productos vendidos, la `meta description` dependía casi por completo del texto original del anuncio/CSV, que puede ser genérico, escaso o muy extenso. Los `title` podían alargarse hasta 155 caracteres.

## Mejora acotada
`src/services/marketplace-product-meta-v32118.js` compone metadatos **solo para fichas públicas de productos en venta**, usando datos reales existentes:

- Título auténtico del artículo, ubicación pública real o «España» si la venta es nacional sin origen conocido, y marca RedLibertad. Longitud recomendada máxima de 78 caracteres para legibilidad (no requisito de Google).
- Descripción de hasta 160 caracteres combinando nombre del artículo, precio expresado en euros, estado «Nuevo» o «Usado» **solo cuando se haya declarado**, ubicación real, pequeña descripción original del anunciante cuando quepa y llamada a la acción honesta.
- La mención «Compra en la web del vendedor» aparece únicamente cuando la lógica **ya existente** `purchaseLink(row)` entrega un enlace de compra verificado. En otros casos, «Consulta el anuncio y contacta con el vendedor».
- El nombre y el texto procedentes de CSV son tratados como contenido no confiable: normalización del espacio y eliminación de etiquetas para metadatos; la función `shell()` existente continúa escapando HTML.
- El texto no afirma tener stock confirmado, envíos gratuitos, envío desde Valencia, transacciones garantizadas, pagos internos ni precios inventados.
- Google puede elegir otros títulos y fragmentos en los resultados; esta modificación **no garantiza** indexación, posición ni CTR.

## Sin cambios
- No cambia el HTML visible de la descripción, precios, fotografías, atributos, enlaces externos de compra ni el origen WooCommerce.
- Sin modificaciones en esquema de base de datos, publicaciones, categorías, sitemaps, robots, canonical, `Product` JSON-LD ni indexabilidad.
- Anuncios «Busco», servicios e inmuebles conservan su metadata y funcionamiento anteriores.
- Piloto gratuito MundoTaza intacto; los pagos de productos siguen ocurriendo exclusivamente en la web del vendedor.
- No activa Stripe LIVE, planes, permisos efectivos, tarifas, IVA ni condiciones legales.

## Pruebas
`npm run test:marketplace-product-meta`: armarios de CSV, moneda en español, estado declarado/no declarado, venta nacional sin origen inventado, enlaces externos, contenido malicioso y anuncios no afectados.

GitHub Actions ejecuta además los controles históricos de JavaScript, Marketplace, importación CSV, indexación, Stripe TEST y PostgreSQL 18. Fusionar solo con verificaciones globales en verde.

## Después de desplegar
1. Abrir una ficha pública de un armario importado, inspeccionar `<title>`, `meta description`, `og:description`, canonical, precio mostrado y enlace de contacto/tienda.
2. Comparar un artículo nuevo, uno usado y uno sin condición especificada: el texto no debe inventar el estado.
3. Comprobar que el botón de compra sigue abriendo la web externa y que las fotografías y fichas no han cambiado.
4. Inspeccionar algunas URL reales en Google Search Console para observar indexación y consultas. Medir cambios en impresiones y CTR con el tiempo; evitar conclusiones rápidas.
