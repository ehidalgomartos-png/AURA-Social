# RedLibertad V3.2.101 — Comprobación externa del despliegue

**Base:** V3.2.100, commit `167ee327abb683d146cecf49a61e4cc249b00577`.

## Objetivo
Una compilación GitHub Actions verde **no** prueba que Coolify haya desplegado su commit. Esta versión añade un proceso de comprobación de producción **independiente**, que solo ejecuta solicitudes públicas GET a `https://redlibertad.com` y no utiliza credenciales, APIs administrativas ni llamadas a Stripe.

## Ejecución
El workflow `.github/workflows/production-readonly-verification-v32101.yml` se activa:
- Cuando se fusiona esta versión o se modifican posteriormente los archivos relevantes en `main`.
- Manualmente desde GitHub Actions con `workflow_dispatch`.

Compara el SHA del commit en GitHub Actions con el `deployedCommit` que Coolify expone mediante `SOURCE_COMMIT`. Comprueba:
1. `GET /api/health`: HTTP 200, `ok:true` y `deployedCommit` igual al SHA esperado.
2. `GET /api/public-config`: commit coherente con el del endpoint de salud.
3. `GET /api/ready`: HTTP 200, `ok:true` y `database:'ready'`.

Se reintenta hasta 10 veces con pausas de 15 segundos para dar margen al despliegue asíncrono. Si falla, el resultado es **despliegue no verificado**, no necesariamente servidor caído. Los logs indican el motivo: DNS, HTTP, commit desconocido, commit diferente o base de datos no preparada.

**Seguridad:** URL de destino fija, HTTPS, sin redirecciones, tiempos de espera estrictos, GET exclusivamente, sin credenciales ni datos personales en logs. El workflow no ejecuta Deploy/Redeploy ni tiene permisos de escritura. El fallo de este workflow **no revierte despliegues** ni cambia el estado de los compradores o tiendas.

## Pruebas
La suite `npm run test:production-deploy-verification` se integra en la CI existente y usa respuestas HTTP simuladas; no hace tráfico a producción dentro de los PR.

## Límites de lanzamiento
El resultado exitoso verifica la identidad del despliegue y los endpoints básicos, **no** certifica que el laboratorio Stripe TEST funcione de extremo a extremo. La prueba manual de Checkout TEST, webhook y cancelación aún es necesaria; Stripe LIVE, precios y contratos definitivos continúan bloqueados hasta aprobación. MundoTaza sigue en piloto gratuito y los productos se cobran en la web del vendedor.

## Si no coincide el SHA
Revisar Coolify → aplicación RedLibertad → Deployment Logs, confirmar que la revisión elegida coincide con el último commit de `main`. Coolify normalmente ofrece `SOURCE_COMMIT` al contenedor en tiempo de ejecución; si se devuelve `null`, verificar la configuración y desplegar de nuevo cuando corresponda. No cambiar claves Stripe ni PostgreSQL para resolver un error de revisión.
